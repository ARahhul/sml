Q5aP-value in hypothesis testing: what it is, why it matters, how to interpret it

Definition

The p-value is the probability of getting a result at least as extreme as the one we observed, assuming the null hypothesis (H₀) is true. H₀ is the “nothing special is happening” claim.

Fig: P-value is the shaded tail area

Importance

  • Tells us whether the result is likely just due to chance.
  • Gives a simple rule for decision: compare p with the significance level α (usually 0.05).
  • Used in every test: t-test, chi-square, ANOVA, regression coefficients.

Interpretation

p-valueMeaning
p ≤ 0.01Very strong evidence against H₀
0.01 < p ≤ 0.05Reject H₀ (significant)
p > 0.05Not enough evidence; fail to reject H₀

Rule: if p < α, reject H₀; otherwise, fail to reject H₀.

Example: A company says its battery lasts 10 hours (H₀). We test 30 batteries and get p = 0.02. Since 0.02 < 0.05, we reject H₀: the battery life is probably not 10 hours.

Common mistakes

The p-value is not the probability that H₀ is true, and a small p-value does not mean the effect is large or important.

Q5bStep-by-step procedure for a two-sample t-test

A two-sample t-test checks whether the means of two independent groups are really different.

  1. State hypotheses. H₀: μ₁ = μ₂ (no difference). H₁: μ₁ ≠ μ₂ (two-tailed) or μ₁ > μ₂ / μ₁ < μ₂ (one-tailed).
  2. Choose the significance level α, usually 0.05.
  3. Check assumptions: the two groups are independent, data is roughly normal in each group, and variances are similar (if not, use Welch’s test).
  4. Collect data and find n₁, n₂, means x̄₁, x̄₂ and standard deviations s₁, s₂.
  5. Calculate the test statistic:
    t = (x̄₁ − x̄₂) / √(s₁²/n₁ + s₂²/n₂)
  6. Find degrees of freedom: df = n₁ + n₂ − 2 (pooled test).
  7. Get the critical value from the t-table for α and df, or get the p-value.
  8. Decide: if |t| > critical value (or p < α), reject H₀.
  9. Conclude in plain words.
Example: Method A: n=10, mean 78, s=6. Method B: n=10, mean 72, s=5. SE = √(36/10 + 25/10) = √6.1 ≈ 2.47. t = 6/2.47 ≈ 2.43. df = 18, critical value (5%, two-tailed) ≈ 2.10. Since 2.43 > 2.10, reject H₀: Method A gives significantly better marks.
Q6aMultiple testing problem, its effect on inference, and how it is corrected

Meaning

When we run many hypothesis tests on the same data, the chance of getting at least one false positive (Type I error: rejecting a true H₀) keeps rising, even if each test uses α = 0.05.

Effect

For m independent tests: P(at least one false positive) = 1 − (1 − α)ᵐ.

No. of tests (m)Chance of a false alarm
15%
1040%
2064%
Example: A researcher tests 20 genes for a link to a disease. Even if none is related, about 1 gene will look “significant” just by luck.

Corrections

  • Bonferroni: use α/m for each test. For 20 tests, α = 0.05/20 = 0.0025. Simple but strict.
  • Holm’s method: sort p-values from smallest; compare the smallest with α/m, the next with α/(m−1), and so on. Stop at the first failure. Less strict than Bonferroni.
  • False Discovery Rate (Benjamini–Hochberg): controls the expected share of false discoveries among the rejected tests. Used when m is very large (genomics, ML feature selection).

Other remedies: plan fewer tests in advance and use ANOVA (one overall test) instead of many pairwise t-tests.

Q6bRole of degrees of freedom in t-tests and other inferential statistics

Definition

Degrees of freedom (df) is the number of values in a calculation that are free to vary.

Example: Five numbers must have mean 10, so their sum is 50. We can pick any 4 numbers freely, but the fifth is then fixed. So df = 5 − 1 = 4.

Formulas

Testdf
One-sample t-testn − 1
Two-sample t-test (pooled)n₁ + n₂ − 2
Chi-square test (table r × c)(r − 1)(c − 1)
Regression with k predictorsn − k − 1

Role

  • df decides the shape of the t-distribution. Small df gives fat tails, which means more uncertainty.
  • It sets the critical value. As df grows, the t-distribution becomes the normal distribution.
  • Used to compute p-values, confidence intervals, and the unbiased variance (dividing by n − 1).

Fewer df means a larger critical value, so stronger evidence is needed to reject H₀.

Q7aFactor (categorical) variables in regression and how they are handled

Definition

A factor variable is a categorical variable that takes a limited set of labels (levels), such as City = Bengaluru, Mysuru, Mangaluru. Regression needs numbers, so factors must be converted.

Handling: dummy (indicator) variables

  1. Pick one level as the reference level.
  2. Make one 0/1 variable for each remaining level. A factor with k levels gives k − 1 dummy variables.
  3. Use these dummies as predictors.
CityMysuruMangaluru
Bengaluru (reference)00
Mysuru10
Mangaluru01

Model: Price = β₀ + β₁(Mysuru) + β₂(Mangaluru). Here β₀ is the average price in Bengaluru, and β₁ is how much Mysuru differs from Bengaluru.

Dummy variable trap

If we make k dummies, they add up to 1 and copy the intercept. This causes perfect multicollinearity (predictors that repeat each other), and the model cannot be solved. So we drop one.

Other types

  • Ordered factors (Low < Medium < High) can be coded 1, 2, 3 if gaps are similar.
  • Methods: one-hot encoding, treatment coding (above), effect coding.

Q8aInterpreting a regression equation with continuous and factor variables

Take the model: Salary = 20 + 3·Experience + 5·Master

Salary is in ₹ thousand per month. Experience (continuous) is in years. Master is a dummy: 1 if the person has a Master’s degree, 0 if Bachelor’s (reference level).

Interpretation

  • Intercept (20): expected salary of a Bachelor’s holder with 0 years of experience.
  • Experience coefficient (3): each extra year adds ₹3 thousand, keeping degree fixed.
  • Master coefficient (5): at the same experience, a Master’s holder earns ₹5 thousand more than a Bachelor’s holder.

Q8bSpline regression, difference from polynomial regression, advantages

Spline regression

The x-axis is divided into pieces at points called knots. In each piece we fit a low-degree polynomial (usually cubic), and the pieces are joined smoothly so the whole curve is continuous, with matching slope and curvature at every knot.

Example: House price against age. Price falls fast for the first 10 years, stays flat in the middle, and rises for heritage homes. A spline with knots at 10 and 60 years follows this naturally.

Polynomial regression

Fits one equation to all the data: y = β₀ + β₁x + β₂x² + … + βₖxᵏ.

Difference

PolynomialSpline
One global curveSeparate low-degree pieces joined at knots
A change in one region affects the whole curveEach region is fitted mostly by its own nearby data
High degree wiggles badly at the endsStable at the ends
Flexibility is set by degreeFlexibility is set by number of knots

Advantages of splines

  • Flexible: can fit complex, non-linear patterns.
  • Local control, so a few odd points do not distort the entire curve.
  • Avoids the wild swings of high-degree polynomials.
  • Natural splines are straight beyond the end knots, so predictions there are safer.
  • Still a linear model, so ordinary least squares and the usual tests work.
Q9aCovariance matrix, importance in discriminant analysis, effect on classification boundaries

Definition

For p variables, the covariance matrix Σ is a p × p table. The diagonal holds each variable’s variance (spread). The other cells hold covariances (how two variables move together). It is symmetric.

Example (Height, Weight): Σ = [ 25   30 ; 30   64 ]. Variance of height = 25, of weight = 64, and the positive covariance 30 means taller people tend to be heavier.

Importance in Discriminant Analysis

  • LDA assumes every class is normally distributed with its own mean μₖ but a common Σ.
  • Discriminant function: δₖ(x) = xᵀΣ⁻¹μₖ − ½ μₖᵀΣ⁻¹μₖ + ln πₖ. A point goes to the class with the largest δₖ.
  • Σ⁻¹ takes care of different scales and correlations between variables. This is the idea behind Mahalanobis distance.

Effect on boundaries

  • Same Σ for all classes (LDA): the boundary is a straight line (a plane in higher dimensions).
  • Different Σₖ per class (QDA): the boundary is curved (quadratic).
  • Larger covariance between variables tilts the data cloud, so the boundary tilts with it.

Fig: Equal covariance gives a straight boundary (LDA)

Q9bInterpreting coefficients and odds ratios in logistic regression, with example

Logistic regression predicts the probability p of a yes/no outcome. Its model is:
ln( p / (1 − p) ) = β₀ + β₁x

Odds = p/(1 − p), i.e. chance of happening vs not happening. ln(odds) is called the log-odds.

Interpretation

  • Coefficient β₁: change in log-odds when x increases by 1 unit. Positive β means higher chance; negative means lower chance.
  • Odds ratio = e^β₁: the number by which the odds are multiplied for each 1-unit increase in x.
Odds ratioMeaning
> 1Odds increase
= 1No effect
< 1Odds decrease
Example: Pass or fail against study hours: ln(odds) = −4 + 0.8·hours.
β₁ = 0.8, so odds ratio = e^0.8 ≈ 2.23. Each extra hour of study more than doubles the odds of passing.
At 5 hours: log-odds = 0, so p = 0.5. At 6 hours: log-odds = 0.8, so p = 1/(1 + e^−0.8) ≈ 0.69.

Note: the coefficient changes the odds by a fixed multiple, not the probability by a fixed amount.

Q10aPrecision, Recall, F1-score and why they matter for imbalanced datasets

Confusion matrix

Predicted PositivePredicted Negative
Actual PositiveTP (true positive)FN (false negative)
Actual NegativeFP (false positive)TN (true negative)
  • Precision = TP / (TP + FP). Of all predicted positives, how many are correct.
  • Recall = TP / (TP + FN). Of all real positives, how many we caught.
  • F1-score = 2 × (Precision × Recall) / (Precision + Recall). The harmonic mean, which is high only when both are high.
Example (fraud detection): 1000 transactions, 20 are fraud. The model catches 12 and wrongly flags 4 genuine ones: TP = 12, FP = 4, FN = 8, TN = 976.
Precision = 12/16 = 0.75. Recall = 12/20 = 0.60. F1 = 2(0.75)(0.60)/1.35 ≈ 0.67. Accuracy = 988/1000 = 98.8%.

Why crucial for imbalanced data

Accuracy is misleading when one class is rare. A useless model that says “genuine” every time scores 980/1000 = 98% accuracy but catches zero frauds (recall = 0). Precision and recall focus on the rare class we really care about, and F1 combines them in one number.

Use recall when missing a positive is costly (cancer, fraud). Use precision when false alarms are costly (spam filter).

Q10bROC curve and how it is used to evaluate classifiers

Definition

The ROC (Receiver Operating Characteristic) curve plots the True Positive Rate against the False Positive Rate at every possible decision threshold.

  • TPR (recall) = TP / (TP + FN)
  • FPR = FP / (FP + TN)

Fig: ROC curves

How it is read

  • Each point on the curve is one threshold. Lowering the threshold catches more positives (TPR up) but gives more false alarms (FPR up).
  • Top-left corner = perfect classifier. Diagonal line = random guessing.
  • A curve closer to the top-left is better.

AUC (Area Under the Curve)

One number to summarise the curve: AUC = 1 is perfect, 0.5 is random, and above 0.8 is generally good.

Uses

  • Compare different classifiers (the higher AUC wins).
  • Choose the best threshold for the problem’s needs.
  • Works independently of the class balance and of one fixed threshold.
